# momiji-rs/homebrew-tap

The [Homebrew](https://brew.sh) tap for [momiji-rs](https://github.com/momiji-rs)
command-line tools.

## Install

```console
$ brew trust --formula momiji-rs/tap/sasso
$ brew install momiji-rs/tap/sasso
$ sasso --version
```

The same for every formula here, `termshot` for instance.

`brew trust --formula` grants the narrowest trust there is: this one formula,
not the tap, so nothing else here — now or later — becomes loadable. Installing
by the fully qualified name records the same trust on its own, but asking for it
first is explicit, and it is what lets you work by short name afterwards
(`brew info sasso`, `brew upgrade sasso`).

## Formulae

| formula | what |
|---|---|
| [`sasso`](Formula/sasso.rb) | A pure-Rust SCSS/Sass → CSS compiler, byte-for-byte compatible with dart-sass. [momiji-rs/sasso](https://github.com/momiji-rs/sasso) |
| [`termshot`](Formula/termshot.rb) | Renders a terminal session's final screen (a PTY log or an asciinema cast) to PNG, text or JSON. [momiji-rs/termshot](https://github.com/momiji-rs/termshot) |

Each formula installs the **prebuilt binary** attached to its upstream release —
macOS and Linux, arm64 and x86_64 — against a SHA-256 recorded in the formula.
Nothing is compiled, so this tap ships no bottles.

[`sync-formula.yml`](.github/workflows/sync-formula.yml) keeps them current:
sasso's is generated by [`dist`](https://github.com/axodotdev/cargo-dist)
upstream and pulled in as it is; termshot's is rendered from its release's
`SHA256SUMS` by [`scripts/termshot-formula.sh`](scripts/termshot-formula.sh).
To publish a release
here immediately rather than waiting for its next scheduled run:

```console
$ gh workflow run sync-formula --repo momiji-rs/homebrew-tap
```
