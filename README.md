# momiji-rs/homebrew-tap

The [Homebrew](https://brew.sh) tap for [momiji-rs](https://github.com/momiji-rs)
command-line tools.

## Install

```console
$ brew install momiji-rs/tap/sasso
$ sasso --version
```

Use that fully qualified form: it trusts only the formula being installed, so no
separate `brew trust` step is needed.

## Formulae

| formula | what |
|---|---|
| [`sasso`](Formula/sasso.rb) | A pure-Rust SCSS/Sass → CSS compiler, byte-for-byte compatible with dart-sass. [momiji-rs/sasso](https://github.com/momiji-rs/sasso) |

Each formula installs the **prebuilt binary** attached to its upstream release —
macOS and Linux, arm64 and x86_64 — against a SHA-256 recorded in the formula.
Nothing is compiled, so this tap ships no bottles.

The formulae are generated by [`dist`](https://github.com/axodotdev/cargo-dist)
upstream and pulled in by
[`sync-formula.yml`](.github/workflows/sync-formula.yml); to publish a release
here immediately rather than waiting for its next scheduled run:

```console
$ gh workflow run sync-formula --repo momiji-rs/homebrew-tap
```
